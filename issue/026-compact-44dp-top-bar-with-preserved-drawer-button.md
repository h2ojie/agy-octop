# Issue 026: 标题栏高度缩窄至 44dp、保留抽屉汉堡按钮与单行跑马灯标题 (v1.0.27)

## 1. 背景与用户反馈
用户反馈：
> “不行，
> 抽屉按钮还是得保留
> 还有，标题栏这么改之后，改窄一点，留更多空间显示消息”

分析用户核心诉求：
1. **抽屉汉堡按钮必须保留**：虽然支持全屏边缘右滑唤出抽屉，但左上角的抽屉按钮是移动端最直观、确定性最高的显式入口，依然必须保留。
2. **顶栏大幅缩窄高程**：Material3 原生 `TopAppBar` 默认强制占用 `64.dp` 容器高度，导致纵向占用了过多屏幕空间。需要定制缩窄为紧凑型顶栏（44dp），为下方的聊天消息流腾出更多展示区域。

---

## 2. 方案实现与优化

### 2.1 44dp 紧凑型顶栏容器
- 废弃强制 64dp 的原生 `TopAppBar` 布局，采用轻量级 `Surface` + `Row` 构建高度精简的顶部操作栏：
  ```kotlin
  Row(
      modifier = Modifier
          .fillMaxWidth()
          .statusBarsPadding()
          .height(44.dp)
          .padding(horizontal = 4.dp),
      verticalAlignment = Alignment.CenterVertically
  )
  ```
- **高程从 64dp 压缩至 44dp**，直接节省出 20dp 的垂直视野，让消息流与吸顶提问卡片向上平移，展现更多对话内容。

### 2.2 左侧保留小巧精致的抽屉按钮 (`Icons.Default.Menu`)
- 左侧恢复抽屉按钮，尺寸缩减为 `36.dp`、图标 `20.dp`，不占用多余横向宽度，与整行 44dp 达到完美垂直居中平衡。
- 点击直接呼出专家与会话列表抽屉。

### 2.3 中间单行跑马灯布局 (`basicMarquee`)
- 管家名称（`15.5.sp` 粗体）与会话标题（`13.sp` 次要色）以居中圆点 `·` 同行并列。
- 会话标题挂载 `basicMarquee(iterations = Int.MAX_VALUE, velocity = 30.dp)`，长标题自适应循环滚动。
- 中间区域依然挂载点击监听，轻触文字同样能唤起侧边栏抽屉。

### 2.4 右侧紧凑更多菜单按钮 (`Icons.Default.MoreVert`)
- 尺寸同步调整为 `36.dp`、图标 `20.dp`，保留“新建会话”、“查看统计”、“模型管理”、“账号设置”等完整功能。

---

## 3. 验证要点
1. **左侧抽屉按钮可用**：点击左上角汉堡图标 `[☰]`，专家侧边栏抽屉秒级划出。
2. **顶栏视觉窄高**：顶部整栏高度显著降低至 44dp，与状态栏贴合自然紧凑，下方的消息流拥有更多纵向展现空间。
3. **单行跑马灯完整性**：管家名字与会话标题同排对齐，超长标题优雅滚动不折行、不截断。
4. **右侧菜单与设置**：点击右侧 `[⋮]` 正常弹出完整二级操作菜单。
